Actionstep is a cloud-based legal practice management platform serving midsize law firms with a REST API for managing matters, contacts, documents, tasks, billing, trust accounting, and law firm financial reporting. The API enables developers to build integrations using Actionstep as the back-end database with built-in data structures and business models for workflow, document management, calendaring, time sheets, billing, and general ledger.

**Areas:** Legal · Practice Management · Law Firms · Matter · Billing · Documents · Trust Accounting · Contacts · Workflows

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Actionstep: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
